# ⚽ فانتازي برو — دليل التشغيل والنشر

تطبيق ويب يشتغل على الموبايل والكمبيوتر، ويضيفه المستخدم للشاشة الرئيسية مثل أي تطبيق.

- **تسجيل الدخول:** Google (تطلع نافذة اختيار الحساب الحقيقية)، Apple، Facebook، X، اسم المستخدم، أو الإيميل.
- **ربط الفريق:** المستخدم يربط فريقه برقم الفريق (Team ID) **مرة وحدة**، وبعدها تنسحب بياناته الحقيقية تلقائياً من موقع الفانتازي الرسمي.

> المشروع ما يحتاج `npm install` ولا أي بناء (build). كله ملفات جاهزة.

## الخطوة 1: إنشاء مشروع Firebase (مجاني)

1. افتح https://console.firebase.google.com واضغط **Add project**، وسمّه مثلاً `fantasy-pro`.
2. من الصفحة الرئيسية للمشروع اضغط أيقونة الويب `</>` وسجّل تطبيق ويب.
3. راح تطلعلك إعدادات بهالشكل. انسخها لملف **`js/config.js`**:
   ```js
   firebase: {
     apiKey: 'AIzaSy...',
     authDomain: 'fantasy-pro-xxxx.firebaseapp.com',
     projectId: 'fantasy-pro-xxxx',
     appId: '1:...:web:...',
   },
   ```
4. **فعّل طرق الدخول** من: **Build ← Authentication ← Sign-in method**:
   - **Email/Password:** فعّلها. هذي لاسم المستخدم والإيميل.
   - **Google:** فعّلها واختار إيميل الدعم. هاي بس.
   - **Apple:** تحتاج حساب Apple Developer (99$ بالسنة) وتسوي Service ID.
   - **Facebook:** سوّي تطبيق على https://developers.facebook.com، وحط App ID وApp Secret بـ Firebase، وانسخ رابط الـ Redirect من Firebase لإعدادات تطبيق فيسبوك.
   - **X (Twitter):** سوّي تطبيق على https://developer.x.com، وحط API Key وSecret بـ Firebase.
   - أي طريقة ما تريدها، أطفيها من `providers` بملف `js/config.js` حتى ما يطلع زرها.
5. **قاعدة البيانات:** **Build ← Firestore Database ← Create database** (اختار Production). بعدين من تبويب **Rules** الصق محتوى ملف `firestore.rules` واضغط **Publish**.

## الخطوة 2: النشر على Vercel (مجاني)

1. ارفع مجلد المشروع على GitHub (مستودع جديد).
2. افتح https://vercel.com، واضغط **Add New ← Project**، واختار المستودع.
3. **Framework Preset:** اختار `Other`. لا تغيّر أي إعدادات بناء.
4. **Environment Variables** (اختيارية، لكن منصوح بيها):
   | الاسم | القيمة |
   |---|---|
   | `ANTHROPIC_API_KEY` | مفتاحك من https://console.anthropic.com. يشغّل المدرب الذكي بالذكاء الاصطناعي |
   | `FIREBASE_API_KEY` | نفس `apiKey` من config.js. يحمي المدرب حتى ما يستخدمه غير المسجّلين |
   | `CLAUDE_MODEL` | اختياري. الافتراضي `claude-sonnet-5-5` |
5. اضغط **Deploy**. راح يطلعلك رابط مثل `fantasy-pro.vercel.app`.
6. **مهم جداً:** ارجع لـ Firebase: **Authentication ← Settings ← Authorized domains ← Add domain** وضيف نطاق Vercel مالتك. بدون هذا، دخول Google ما يشتغل.

✅ خلص! افتح الرابط من موبايلك، سجّل دخول، واكتب رقم فريقك.

**تحويله لتطبيق على الموبايل:**
- **آيفون:** Safari ← مشاركة ← **إضافة إلى الشاشة الرئيسية**.
- **أندرويد:** Chrome ← ⋮ ← **إضافة إلى الشاشة الرئيسية**.

## الخطوة 3: تعيين نفسك مشرفاً (للوحة الإدارة)

1. سجّل دخول بالتطبيق مرة وحدة.
2. Firebase Console ← Authentication ← Users ← انسخ **User UID** مالتك.
3. Firestore ← **Start collection** باسم `admins` ← Document ID = الـ UID ← ضيف أي حقل (مثلاً `role: "owner"`).
4. سوّي تحديث للتطبيق، وتطلع "لوحة الإدارة" بالقائمة.

> بالوضع التجريبي (بدون Firebase) أي حساب اسم مستخدمه `admin` يكون مشرف.

## التجربة على جهازك قبل النشر

تحتاج Node.js 18 أو أحدث:

```bash
node dev/server.mjs          # بيانات حقيقية من الفانتازي
node dev/server.mjs --mock   # بيانات تجريبية بدون إنترنت — رقم الفريق: 123456
FPL_MOCK_LIVE=1 node dev/server.mjs --mock   # نفس الشي مع جولة "مباشرة" لتجربة النقاط والإشعارات اللحظية
```

بعدها افتح http://localhost:3000

إذا ما حطيت إعدادات Firebase، يشتغل التطبيق بـ"وضع التجربة". الحسابات تنحفظ على نفس الجهاز بس.

## أسئلة مهمة

**ليش ما يسجّل دخول بحساب الفانتازي الرسمي نفسه؟**
موقع الفانتازي الرسمي ما يسمح لأي تطبيق خارجي يسجّل دخول بحسابك أو يعدّل فريقك. كل التطبيقات المعروفة (مثل FPL Review وLiveFPL) تشتغل برقم الفريق. ميزتها إنك ما تعطي كلمة مرورك لأحد.

**الانتقالات اللي أسويها بالتطبيق تتنفّذ بفريقي؟**
لا. هي **خطة** تجربها وتشوف تأثيرها على نقاطك المتوقعة. التنفيذ الفعلي يكون بتطبيق الفانتازي الرسمي.

**ليش فريقي بالتطبيق ما يبيّن آخر انتقال سويته؟**
الفانتازي الرسمي يُظهر انتقالات الجولة القادمة للعامة **بعد الموعد النهائي** فقط. لهذا التطبيق يبدأ من آخر فريق رسمي، وإنت تضيف انتقالاتك الجديدة بالخطة.

**الانتقالات المجانية دقيقة؟**
هي **تقديرية**، محسوبة من سجل جولاتك (الحد الأقصى 5)، لأن الموقع ما ينشر الرقم بشكل عام. وسعر البيع الفعلي ممكن يختلف شوية عن السعر الحالي.

**شنو "النقاط المتوقعة"؟**
للجولة القادمة نستخدم تقدير الفانتازي الرسمي نفسه (ep_next). للجولات اللي بعدها نحسبها من الفورم ومعدل النقاط والدقائق وصعوبة المباريات الرسمية وجاهزية اللاعب. تدعم الجولات المزدوجة والفارغة.

**إذا موقع الفانتازي وقف؟**
السيرفر يحفظ آخر نسخة من البيانات ويرجّعها. بين الجولات (وقت التحديث) الموقع يرجّع رسالة "يتحدّث حالياً" لدقائق.

## هيكل المشروع

```
index.html            الواجهة الأساسية
styles.css            التصميم
js/config.js          ← إعداداتك (Firebase وطرق الدخول)
js/app.js             الدخول والتنقل والتحميل
js/auth.js            الحسابات والدوريات الخاصة والإدارة (Firebase أو محلي)
js/fpl.js             جلب البيانات مع كاش ووقت آخر تحديث
js/engine.js          محرك النقاط المتوقعة والتشكيلة والبدلاء
js/notify.js          توليد الإشعارات من البيانات الحقيقية
js/views/*.js         كل قسم بملف
api/fpl.js            سيرفر وسيط لبيانات الفانتازي (كاش + حماية من الحظر + حالة السيرفر)
api/coach.js          سيرفر المدرب الذكي (Claude) — المفتاح بالسيرفر فقط
api/_mock.js          بيانات تجريبية
firestore.rules       قواعد الحماية
```

**الأمان:**
- كل مستخدم يقرا ويكتب ملفه بس، وما يگدر يرفع الحظر عن نفسه.
- الدوريات الخاصة: العضو يضيف/يحذف نفسه بس، المالك والمشرف يديرون الدوري.
- الإعدادات العامة يكتبها المشرف بس، وقائمة المشرفين ما تنعدل إلا من الكونسول.
- كلمات المرور يحفظها Firebase مشفّرة، ومفتاح الذكاء الاصطناعي بالسيرفر بس.

## شنو يحتاج إعداد خارجي

| الميزة | المطلوب |
|---|---|
| حسابات سحابية ودخول Google/Apple/Facebook/X | Firebase (الخطوة 1) — بدونه يشتغل وضع تجريبي محلي |
| المدرب بالذكاء الاصطناعي | `ANTHROPIC_API_KEY` بـ Vercel — بدونه محرك تحليل محلي |
| إشعارات والتطبيق مسكّر | Firebase Cloud Messaging + Service Worker (غير مضاف) — الحالي يشتغل والتطبيق مفتوح |
| التسديدات والفرص الكبيرة | غير متوفرة بواجهة الفانتازي الرسمية، تحتاج مزود بيانات مدفوع |
| الترتيب المباشر أثناء الجولة | الفانتازي ما ينشره إلا بعد نهاية الجولة |
| صور اللاعبين وشعارات الأندية | محمية بحقوق — التطبيق يستخدم قمصان بألوان الأندية |
